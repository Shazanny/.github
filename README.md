# Profil de l'orga Shazanny

Ce dépôt sert à la page [github.com/Shazanny](https://github.com/Shazanny) : GitHub y affiche
[`profile/README.md`](profile/README.md).

Pour régénérer les images animées (bannière, cartes, technos…) :

```bash
pip install fonttools pillow
python profile/assets/generer.py
```

Le logo est dans [`profile/assets/logo/`](profile/assets/logo/) : `shazanny-512.png` pour l'avatar
de l'orga, les SVG pour le reste.
